# 📅 Day 2: SQL Practice & Project Development

Day 2 focused on **solving practical SQL questions and developing database projects using MySQL**. Along with query practice, we worked on two database projects: a Food Ordering System and an Uber Database System.

### 🧠 Topics Covered

- Hands-on SQL query practice
- Data filtering and sorting
- Aggregate functions and grouping
- Joins between multiple tables
- Primary keys and foreign keys
- Applying SQL concepts to practical database projects

### 🍔 Project 1: Food Ordering System

**Project Description:**

The Food Ordering System is a database project developed using MySQL to manage user information and food orders.

**Main Tables:**

- `userDetails` — Stores user information, including email, password, and phone number.
- `orderDetails` — Stores food order information, including item name, food choice, quantity, amount, status, location, order date, payment mode, and rating.

**Key Functionalities:**

- Store and retrieve user details.
- Maintain food order records.
- Manage food items, quantities, prices, and order statuses.
- Establish relationships between users and orders using foreign keys.
- Retrieve and analyze order information using SQL queries.

### 🚕 Project 2: Uber Database System

**Project Description:**

The Uber Database System was developed as part of the SQL practice session to understand how a ride-booking application manages structured data using MySQL.

The project focuses on database design, table creation, relationships, and executing SQL queries to manage and retrieve ride-related information.

**Learning Highlights:**

- Practiced designing database tables for a ride-booking system.
- Worked with structured data and table relationships.
- Applied primary keys and foreign keys.
- Practiced SQL queries for retrieving and filtering records.
- Used joins and aggregate functions to analyze database information.
- Improved understanding of how relational databases can support real-world applications.
