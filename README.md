# Day 1 – SQL Fundamentals with MySQL

📅 **Day 1: SQL Fundamentals — MySQL**

Day 1 of the Technical-Ycap Training Program focused on understanding SQL fundamentals and working with relational databases using MySQL. The session covered database creation, table management, data manipulation, constraints, aggregate functions, and relationships between tables.

## 🧠 Topics Covered

- Introduction to SQL and Relational Database Management Systems (RDBMS)
- Database and table creation using `CREATE`
- Inserting records using `INSERT`
- Retrieving data using `SELECT`
- Updating records using `UPDATE`
- Deleting records using `DELETE`
- SQL constraints and keys (PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL)
- Filtering records using `WHERE`
- Sorting records using `ORDER BY`
- Aggregate functions (`COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`)
- Grouping records using `GROUP BY` and `HAVING`
- Joins and relationships between tables

## 🚀 Learning Highlights

- Practised basic to intermediate SQL queries.
- Created and managed relational databases using MySQL.
- Performed CRUD operations on database tables.
- Applied constraints to maintain data integrity.
- Used aggregate functions to perform data analysis.
- Practised joins to retrieve data from multiple related tables.
- Solved practical database-related problems.

## 🎯 Learning Outcomes

- Developed a strong foundation in SQL and relational databases.
- Gained practical experience in writing and executing MySQL queries.
- Understood database structures, table relationships, and data integrity.
- Learned to retrieve, manipulate, and analyze structured data.
