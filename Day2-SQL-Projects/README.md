# Day 2 – SQL Practice and Projects

## Projects

### 1. Food Ordering System
A MySQL database project designed to manage user details and food orders. It includes database operations involving food items, quantities, amounts, order status, payment mode, location, and ratings.

**File:** `food_ordering.sql`

### 2. Uber Database System
A database practice project based on a ride-booking application. It focuses on relational database concepts, table relationships, SQL queries, and database operations.

**File:** `uberdb.sql`

## Concepts Practiced
- Database and table creation
- Primary and foreign keys
- CRUD operations
- SQL joins
- Filtering and sorting
- Aggregate functions

## Practical Work
This folder contains the SQL scripts for both projects completed during Day 2 of the Technical-Ycap training program.
